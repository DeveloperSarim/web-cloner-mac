Three jobs, one window

Pick what you want from a site. The pages arrive in a list as they finish, with sizes and failures in plain sight.

The images other cloners leave behind

Most sites serve their pictures and fonts from a separate domain, and some write them in a way plain wget reads as a broken path. Web Cloner finishes the job: it reads the saved pages, fetches what is still missing and points every reference at the local file.

What you also get

The parts that turn a download into something you can still use months later.

A sitemap every run

A standard sitemap.xml of every page found, whether you saved the site or only scanned it.

Speed you set

Polite waits between requests and caps the rate. Fast does not pause. Your call, per job.

Updates in place

The app checks for a new release on launch and replaces itself. Nothing to download twice.

The exact command

Every option maps to a wget flag, and one button copies the whole command.
