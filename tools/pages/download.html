Get the app

Two ways, both free. The disk image is the usual route. Homebrew is handy if you already live in a terminal.

Download Web Cloner VERSION All releases
brew install --cask DeveloperSarim/tap/web-cloner

What it needs

  • macOS 13 Ventura or later.
  • Any Mac from the last decade. One universal build runs natively on Intel and Apple Silicon.
  • wget. The app installs it through Homebrew if it is missing, and installs Homebrew first when you do not have that either. The cask above pulls it in for you.
  • About 6 MB of disk for the app. Saved sites live wherever you point them.

Opening it the first time

Web Cloner is signed so it runs, but it is not notarised by Apple, which costs 99 dollars a year. macOS therefore asks about it once. Right-click the app in Applications, choose Open, then confirm. After that it opens normally.

Installing with Homebrew and want to skip that prompt? Add the flag:

brew install --cask --no-quarantine DeveloperSarim/tap/web-cloner

Updates

Nothing to do. On launch the app asks for the newest release and, if there is one, offers to install it in place. Your settings and saved sites stay where they are. There is also Web Cloner then Check for Updates in the menu bar.

Checking the file you downloaded

If you want to confirm the disk image is the one that was published, compare its checksum:

shasum -a 256 ~/Downloads/WebCloner.dmg

The expected value for the current version sits in the Homebrew cask, which Homebrew checks for you on every install.

Building it yourself

The app is a handful of Swift files with no dependencies. With the Xcode command line tools installed:

git clone REPO.git cd web-cloner-mac ./build.sh

That produces the app and a disk image as a universal binary. Full Xcode is not required.

Removing it

Drag the app to the Trash, or brew uninstall --cask web-cloner. Sites you saved are plain folders and stay untouched until you delete them yourself.
